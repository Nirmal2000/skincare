# Color Palette

## Primary Colors

Main White - #F8F9FA (Used for backgrounds and clean surfaces)
Main Dark Green - #0A5F55 (Primary brand color for buttons, icons, and accents)

## Secondary Colors

Secondary Light Green - #4CAF94 (Used for hover states and secondary elements)
Secondary Pale Green - #E6F4F1 (Used for backgrounds, selected states, and highlights)

## Accent Colors

Accent Cyan - #00BFA5 (Used for important actions and notifications)
Accent Yellow - #FFD54F (Used for warnings and highlights)

## Functional Colors

Success Green - #43A047 (Used for success states and confirmations)
Error Red - #E53935 (Used for errors and destructive actions)
Neutral Gray - #9E9E9E (Used for secondary text and disabled states)
Dark Gray - #424242 (Used for primary text)

## Background Colors

Background White - #FFFFFF (Pure white for cards and content areas)
Background Light - #F5F7F9 (Subtle off-white for app background)
Background Dark - #263238 (Main background for dark mode)

# Typography

## Font Family

Primary Font: SF Pro Text (iOS) / Roboto (Android)
Fallback Font: Inter (Web fallback)

## Weights

Regular: 400
Medium: 500
Semibold: 600
Bold: 700

# Text Styles

## Headings

H1: 28px/32px, Bold, Letter spacing -0.2px, Used for screen titles and main headers

H2: 24px/28px, Bold, Letter spacing -0.2px, Used for section headers and card titles

H3: 20px/24px, Semibold, Letter spacing -0.1px, Used for sub-section headers and important text

## Body Text

Body Large: 17px/24px, Regular, Letter spacing 0px, Used for main reading text in transcriptions

Body: 15px/20px, Regular, Letter spacing 0px, Standard text for most UI elements

Body Small: 13px/18px, Regular, Letter spacing 0.1px, Secondary information and supporting text

## Special Text

Caption: 12px/16px, Medium, Letter spacing 0.2px, Used for timestamps, metadata, and labels

Button Text: 16px/24px, Medium, Letter spacing 0.1px, Specifically for buttons and interactive elements

Link Text: 15px/20px, Medium, Letter spacing 0px, Main Dark Green, Clickable text within the application

# Spacing System

4dp - Micro spacing (Between related elements)
8dp - Small spacing (Internal padding)
16dp - Default spacing (Standard margins)
24dp - Medium spacing (Between sections)
32dp - Large spacing (Major section separation)
48dp - Extra Large spacing (Screen top/bottom padding)

# Motion & Animation

Standard Transition: 200ms, Ease-out curve
Emphasized Transition: 300ms, Spring curve (Tension: 300, Friction: 35)
Micro-interactions: 150ms, Ease-in-out
Page Transition: 350ms, Custom cubic-bezier(0.2, 0.8, 0.2, 1)

# Dark Mode Variants

Dark Background: #121212 (Main dark background)
Dark Surface: #1E1E1E (Card background)
Dark Main Green: #26A69A (Adjusted for better contrast)
Dark Primary Text: #EEEEEE
Dark Secondary Text: #B0BEC5
